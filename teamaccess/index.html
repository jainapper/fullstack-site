Starshipit connection and local data.

Starshipit API

      
Every Starshipit child account has its own API key (Settings → API inside that account) and the whole login shares one subscription key. Each synced order is tagged with its child account as the client. Keys live only in this browser. Starshipit calls are routed through the Fullstack proxy automatically, so no extra setup is needed; set a Proxy base URL only if you want to use your own.
